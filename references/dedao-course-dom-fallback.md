# 得到课程页 DOM 兜底抓取

适用：`https://www.dedao.cn/course/detail?id=...`

## 为什么需要兜底

得到课程详情页由前端渲染。学习助手若只走通用网页抓取，可能抓到登录页、导航和学习统计占位，出现：

- `NaN 今日学习`
- `账户充值 / 登录 / 注册`
- `得到一下 / 知识城邦`
- 摘要没有课程结构，只是页面壳文本

这些是抓取污染信号，不能直接作为 Obsidian 正文。

## 推荐流程

1. 运行学习助手主脚本，生成收件箱初稿和知识库草稿。
2. 打开课程详情页。
3. 点击「课程内容」。
4. 从浏览器可见 DOM 抽取：
   - 课程标题
   - 副标题
   - 价格
   - 试读 / 可试读
   - 已更新 / 总讲数
   - 学习人数
   - 购买须知
   - 当前可见/已展开目录
5. 如果只拿到部分目录，笔记中写“当前公开可见/当前展开”，不要补全未知讲次；若页面懒加载，先滚动到底部再复抓，避免只保存前 30 讲。
6. 记录授权状态证据：页面是否显示登录/注册/购买按钮，接口 `class_info.is_subscribe` 是否为 1。`is_subscribe=0` 时只能保存公开目录与“已购正文待补”，不能声称抓到正文。
7. 可用接口线索：`/pc/bauhinia/pc/class/info` 常返回 `chapter_list`；购买态可探测 `/pc/bauhinia/pc/class/purchase/info` 与 `/pc/bauhinia/pc/class/purchase/article_list`，但只有在登录且已购授权成立时才应期待正文/购买列表。
8. 在 Obsidian 生成干净课程总览，而不是修补污染摘要。

## 输出建议

保存为课程总览笔记，结构：

```md
# 课程名

## 来源
- 平台：得到
- URL：...
- 抓取时间：...
- 状态：公开课程页 / 已购内容待补

## 课程元数据
...

## 课程定位
...

## 当前可见目录
...

## 学习助手判断
- 价值评分
- 入库决策
- Wade 可复用方向

## 待补
- 完整 55 讲目录
- 已购正文/音频笔记
- 逐讲知识卡片
```
